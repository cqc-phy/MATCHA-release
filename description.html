MATChing HEFT Amplitudes

MATCHA is a Mathematica package designed to perform symbolic matching between ultraviolet (UV) theories and the Higgs Effective Field Theory (HEFT).

Get started See example GitHub

Authors: Raquel Gómez-Ambrosio and Carlos Quezada Calonge · carlosariel.quezadacalonge@unito.it

Description

MATCHA automates the workflow required to match UV models onto HEFT at LO using an amplitude-level approach. It generates UV diagrams, computes symbolic UV amplitudes, matches them to the corresponding HEFT structures, and extracts effective coefficients such as a_n, d_n and c_n up to any desired Higgs field order.

What MATCHA automates

  • Generation of UV diagrams using FeynArts.
  • Symbolic calculation of UV amplitudes using FormCalc.
  • Matching UV amplitudes to the corresponding HEFT structures.
  • Extraction of effective coefficients (a_n, d_n, and c_n) to arbitrary Higgs order.
