Requirements and Installation

Requirements

In the accompanying paper, MATCHA was tested with the following versions:

  • Mathematica: version 12.0
  • FeynArts: version 3.11
  • FormCalc: version 9.8

FeynRules is not required to run MATCHA directly. However, the user must provide the FeynRules output of the UV model: the .mod and .gen model files used as input by FeynArts.

Although MATCHA loads the full UV model and its definitions, when generating the FeynRules output it is recommended to use

FeynRules
CouplingRename -> False

This keeps the dependence on the heavy masses explicit in the generated model files.

Finally, the UV parameters should also be chosen such that no divergences are produced in the large-mass limit.

Installation

The simplest way to install MATCHA is to clone the public GitHub repository in a directory of your choosing:

Clone repository 
git clone https://github.com/cqc-phy/MATCHA-release

After cloning the repository, configure the paths used by MATCHA. In Config.m, locate the corresponding entries and set the routes to FeynArts, FormCalc, the model files, and the directory where MATCHA will store its output:

Config.m 
$MATCHARoutesConfig = <|
  "FeynArtsRoute" -> "/path/to/FeynArts",
  "FormCalcRoute" -> "/path/to/FormCalc",
  "ModelPath" -> "/path/to/Models",
  "OutputDirectory" -> "/path/to/MATCHA"
|>;

At this point, MATCHA is ready to use.
